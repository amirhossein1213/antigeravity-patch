## What to Include When Asking for Help

To get the fastest response, include:

- **OS version:** Windows 10/11, build number
- **Antigravity version:** Antigravity IDE or Antigravity 2.x
- **Proxy tool:** Clash Verge, v2rayN, Clash, Sing-box, etc.
- **Port:** Local HTTP port (e.g., 7897, 7890, 10809)
- **Error messages:** Exact text of any errors
- **Steps to reproduce:** What you did, what happened, what you expected
